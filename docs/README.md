Generating the docs
===================

The site is built with [MkDocs](http://www.mkdocs.org/) plus the
[mkdocstrings](https://mkdocstrings.github.io/) plugin (auto-generated API
reference). Sources live under `docs/docs/`; the navigation and plugin config
are in `docs/mkdocs.yml`.

Setup
-----

From the repository root:

    pip install -e .                      # so mkdocstrings can resolve richio
    pip install -r docs/requirements.txt  # mkdocs + mkdocstrings[python]

Build / serve
-------------

From the `docs/` directory:

    mkdocs serve            # live preview at http://127.0.0.1:8000
    mkdocs build --strict   # one-off build into docs/site (fails on broken links)

`mkdocs build` regenerates `docs/site/` (build output — git-ignored).

Notes
-----

* The API reference is generated by static analysis (griffe), so the
  `richio.render` and `richio.shockfinder` pages build even without their
  optional runtime deps (`yt`, `numba`, `scipy`) installed.
* Add or rename simulation fields in `richio/config.py` (`FIELD_REGISTRY`) — the
  docs read aliases/units from there.
