# `richio.data`

Snapshot loading and the core `Snapshot` API. The primary entry point is
[`load`](../getting-started/quickstart.md). Integer snapshot indexing returns
`richio.Particles`; see [Reading particles](../guide/fields-and-aliases.md#reading-particles)
for collection indexing, column access, and tracing across snapshots.
